
HTML_CSS_Portfolio

FILES
1. index.html - Website structure and content.
2. style.css - Website design and styling.
3. cv.txt - Sample CV for the download button.
4. README.txt - Instructions for running the website.

HOW TO OPEN
1. Open Visual Studio Code.
2. Open the HTML_CSS_Portfolio folder.
3. Open index.html.
4. Right-click and select Open with Live Server.
5. The website will open in your browser.

IMPORTANT
- Keep index.html and style.css in the same folder.
- Replace the sample email and phone number with your own.
- The profile image is currently represented by initials.
- The contact form uses a mailto link and does not use a database.
- Test the navigation links and Download CV button.
